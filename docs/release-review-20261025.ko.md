# 출시 전 검토와 추가 회귀 검사

기준 PR head는 8352adcd5ad0783f9dc6dcd7a236056e464512e9, 비교 master는 b8ca0ed6a4fbeb1b09f6999da3313bcedb834066이다. 사용자 보존 이력과 한국어 기능별 커밋을 유지한다.

추가 검토에서 과업/날짜 기록 삭제 응답이 새 편집 초안을 비우는 경로를 확인했다. 지연된 합성 DELETE 응답 전에 새 과업 편집을 시작하는 두 회귀 검사는 수정 전 실패했고, 세션·편집 대상 확인을 추가한 뒤 통과했다. 요청의 삭제 대상은 원래 ID/날짜를 사용하며, 완료 후 현재 세션의 목록만 재조회한다.

기존 검증된 Linux 단일 파일 IBus 보정을 별도 커밋으로 포함했다. 입력 보정을 끈 것이 아니라 동일 키코드 변환을 Avalonia.FreeDesktop에 빌드 시 적용한다. 출처·패키지·재현 절차는 vendor/avalonia/linux-ibus에 있다. Browser 패키지 qa-ime.6과 Android 입력 경로는 이 변경 대상이 아니다.

검사 결과: 격리 SQLite 백엔드 65개, 합성 HTTP 모델 21개, 화면 없는 UI 14개, Browser 초기화 스크립트 검사 통과. 기존 Clipboard API 사용 중단 예정 경고가 남는다. 운영 DB나 실제 계정으로 테스트하지 않았다. 전체 보안 자동 스캔은 스킬 참조 문서 조회 장애로 수행하지 못했으며 인증·계정 격리·기존 사용자 보존·자격 증명 및 정적 웹 호스팅 변경은 직접 검토했다. 취약점 부재의 증명은 아니다.

배포된 1e66246 기준으로 backend 코드·DB 모델·마이그레이션은 변경하지 않는다. 기존 JWT 키·외부 MariaDB 설정·데이터 볼륨은 운영 인계에서 보존해야 한다. 추가 운영 비밀 수집/DB 복원/설정 변경은 수행하지 않는다.

무변경 재조회 최적화의 측정 조건과 한계는 unchanged-refresh-regression.ko.md를 따른다. 비가상화, 변경 저장 비용, 빠른 IME 입력의 미확정 현상은 남으며 별도 성능 실험을 출시 후보에 섞지 않았다. Windows 실제 실행, 새 릴리스 실폰 IME 전 행렬, 운영 사이트 로그인은 빌드/기존 검사만으로 완료로 간주하지 않는다.
