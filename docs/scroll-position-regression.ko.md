# 키보드 닫힘·목록 재조회 위치 보존

키보드가 닫힐 때 가시 영역이 커져도 포커스된 편집기를 다시 자동 노출해 사용자 위치를 되돌리던 동작을 제한한다. IME 가림 높이가 양수인 경우에만 요청을 예약하고 실행 직전에도 확인한다. 키보드가 열릴 때와 열린 상태의 편집기 포커스 노출은 유지한다.

동일 날짜에서 Tasks가 교체되기 직전에 가시 과업 ID와 상대 위치를 기록한다. 선택 복원 템플릿 처리가 끝난 뒤 위치를 복구한다. 새 선택·날짜·인증 상태·DataContext 변경은 복원보다 우선하며, 삭제된 항목은 새 스크롤 범위로 제한한다. 더 최신 교체가 있으면 오래된 예약을 무시한다.

통합 UI 검사는 기존 IME 옵션 포함14/14, 가짜 HTTP 모델 검사17/17 통과했다. 같은 목록·역순 정렬·앵커 삭제·다른 선택·신규 과업·날짜 변경·키보드 정책을 검사한다. 제품 코드에 진단 타이머나 Android 추적 코드는 넣지 않았다.

독립 Android API35 에뮬레이터 후보 검증에서는 키보드 닫힘 동안 offset137.517 유지와 불필요 BringIntoView0회, 재조회182.413→182.413을 확인했다. 편집기 재탭 시 키보드 위 노출, 다른 과업 선택, 새 과업 편집 진입도 확인했다. 이 수치는 해당 담당의 계측 사본 결과이며 배포 APK의 재측정 결과가 아니다.

이 변경은 최종 위치를 보존하는 수정이다. 목록 재조회 내부 약83ms의 일시적 오프셋 변화, 비가상화 비용, 렌더 프레임 지연은 남는다. 모든 스크롤 성능을 해결했다고 주장하지 않는다. 계층 확장·접힘, 행 높이가 크게 달라지는 장문 제목, 실기기와 다른 IME는 추가 검증 범위다.

기존 ed162d9 웹 배포 전달물과 별개 후속 변경이며 기존 아티팩트를 교체하지 않는다. backend·DB·API는 변경하지 않았다.
